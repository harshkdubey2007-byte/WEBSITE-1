#Learn-by-doing Projects

Projects You'll Build

Work on industry projects from leading companies. Build a portfolio that stands out and demonstrates your practical expertise to employers.

Project 1

Network Infrastructure Discovery & Topology Analysis

Perform a structured analysis of a local network environment to identify connected devices, IP addressing schemes, and communication paths, then document the logical network topology.

Project 2

Virtualized Penetration Testing Lab Architecture & Deployment

Design and deploy a controlled virtualized penetration testing environment using industry-recognized security distributions to simulate real-world assessment scenarios safely and ethically.

Project 3

Linux System Command-Line Operations & Environment Analysis

Conduct a structured study of core Linux command-line utilities to analyze system navigation, file management, permissions, and process monitoring within a controlled lab environment.

Project 4

Open-Source Intelligence (OSINT) & External Footprint Analysis

Perform a passive and active reconnaissance exercise on the wscubetech website to identify exposed digital assets, domain information, and publicly available metadata without active intrusion.

Project 5

Network Service Enumeration & Vulnerability Surface Assessment

Conduct a structured network enumeration exercise on a deliberately vulnerable virtual machine (e.g., Metasploitable2) to identify open ports, exposed services, and potential misconfigurations.

Project 6

Controlled Exploitation & Post-Exploitation Documentation

Simulate a controlled exploitation scenario in a vulnerable lab environment (e.g., Metasploitable2) and document the process of obtaining command-line access, including root cause analysis and remediation recommendations.

Project 7

Credential Exposure Analysis via Insecure Transmission Channels

Analyze insecure credential transmission mechanisms within a controlled lab to demonstrate risks associated with unencrypted URL parameters and improper input handling.

Project 8

Password Hash Analysis & Cryptographic Evaluation

Perform cryptographic analysis on provided password hashes within a controlled lab environment to evaluate password strength and understand common weaknesses in hashing implementations.

Project 9

Security Operations Center (SOC) & SIEM Conceptual Framework Analysis

Prepare a structured theoretical analysis explaining the role of a Security Operations Center (SOC), the purpose of SIEM systems, and the importance of data security fundamentals in modern defensive cybersecurity operations.
