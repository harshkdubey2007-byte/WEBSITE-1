Tips for better results

Check your top pages

Start with your home page, service pages and most-visited blog posts. Broken links there hurt the most.

Fix with redirects

If one of your own pages moved, add a 301 redirect so old links and Google go to the new page.

Check every few months

Other websites delete pages all the time. A quick check every 2 to 3 months keeps your site clean.

We open the page and its links from our server to check them, the same way a search engine does. Nothing is saved.

What is a broken link?

A link that leads to a page that does not exist (404), a server error (500) or a website that is gone. They annoy visitors and waste the value of your links for SEO.

Why do some links say Check manually?

Some websites, like LinkedIn and Instagram, block automatic checkers and return 403 or 999. The link may work fine for people, so open it yourself to confirm.

Does it check my whole website?

It checks every link on the one page you enter, up to 150 links. Run it on each important page, or ask us about a full-site SEO audit.
